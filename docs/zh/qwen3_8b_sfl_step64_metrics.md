## 启动期观察

- 三个 G3-only / G3-heavy 实验（`G3_2 + G3_2_2`、G3 triple、G3 triple + G2 0.25）在 step 64 已给出 68.00–72.00 的 Hard，但 IID 仅 48.94–53.07；这与其最终「Hard 高、IID 低」的形态一致。
- `G2_half + G3_2` 原始 run 在 step 64 的 RM / Hard 为 72.67 / 60.00；seed 43 在相同 step 已是 74.50 / 64.00，但最终反而从 76.00 / 62.50 变为 73.67 / 59.00。因而 step 64 的单点表现不能预测最终最优 run，也支持启动阶段路径具有显著随机性。
- 基座在 step 0 的绝对 score 为 37.03 / 37.77、Hard 为 68.50、score diff 为 3.8078；`G2_half + G3_2` 到 step 64 则为 25.97 / 26.20、Hard 60.00、score diff 1.7592。这直接量化了启动期的尺度收缩与 Hard 下滑。所有非 margin B1/B2 实验的 step-64 absolute score 均已收缩至约 24.7–27.5；B1/B2 保留约 45 的绝对尺度且有极高记录 score diff（6.97 / 10.15），说明数据/目标可改变启动期 score 尺度。后续应连同 step 0、16、32、48、64 的分布看轨迹，而不能仅比较 step 64。
