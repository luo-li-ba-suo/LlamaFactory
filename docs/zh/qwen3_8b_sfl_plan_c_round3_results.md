# Qwen3-8B SfL Plan C：Round 3 结果

## 设置

Round 3 均从相同的 `G2` 主干数据开始，在 Round 2 的分支数据上继续加入 Round 3 数据，训练 Qwen3-8B SfL LoRA（rank 16）。所有实验训练 2 个 epoch，8 卡、每卡 batch size 2、gradient accumulation 16。

- `G2G3_2 -> G2G3_3`：加入 G2+G3 路线的 Round-3 active 数据。
- `G2G3_2 -> G3G3_3`：加入 G3+G3 路线的 Round-3 active 数据。
- `pos_half`：相同路线，但将新增数据中的正样本下采样至一半。

IID 为 B1--B5 的 750 条样本平均准确率；RM Bench 为 chat、code、math、safety 的 600 条样本平均准确率。

## 与上一版模型的对比

四个 Round 3 配置都保留了 `G2 + G3_2` 的训练数据，并在此基础上加入不同的 Round-3 数据；训练仍从 Qwen3-8B 基座开始，而不是直接继续上一版 LoRA。因此“上一版模型”以 Round 2 的 `G2 + G3_2` 为共同基线（IID 76.40%，RM Bench 72.58%）。

| 实验 | IID：上一版 → 当前 | IID 变化 | RM Bench：上一版 → 当前 | RM Bench 变化 |

`G2G3_2 -> G2G3_3` 是最有效的上一版增强：IID 大幅提升主要来自 B4/B5，同时 RM Bench 也小幅上升。`G2G3_2 -> G3G3_3` 则是更偏向 RM Bench 的增强，IID 基本持平但 RM Bench 四项中 Code、Math、Safety 均有改善。半正样本版本没有复现这两条全量数据路线的整体增益。

## 结论

1. 若目标是 IID，选择全量正样本的 `G2G3_2 -> G2G3_3`。它在 B3--B5 全部最佳，并以 80.94% 取得最高 IID。
2. 若目标是 RM Bench，选择全量正样本的 `G2G3_2 -> G3G3_3`。其 RM Bench 为 73.50%，比前者高 0.33 个百分点，但 IID 低 4.14 个百分点。
3. 半正样本没有改善总体结果：在 G2G3 路线上 IID/RM Bench 分别下降 1.07/1.67 个百分点；在 G3G3 路线上下降 3.33/1.00 个百分点。其唯一局部收益是 G3G3 路线的 chat（+2.00）和 hard（+0.50），不足以抵消 B4/B5 的明显退化。
